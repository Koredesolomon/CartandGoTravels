# Website fonts

These unmodified font files are bundled for `next/font/local`, so builds do not depend on Google Fonts downloads. Keep them and their licences in version control.

Downloaded from the official Google Fonts repository on 2026-10-10:

- [Inter](https://github.com/google/fonts/tree/main/ofl/inter): `Inter[opsz,wght].ttf`, stored as `Inter-Variable.ttf`; licence `inter-OFL.txt`.
- [Fraunces](https://github.com/google/fonts/tree/main/ofl/fraunces): `Fraunces[SOFT,WONK,opsz,wght].ttf`, stored as `Fraunces-Variable.ttf`; licence `fraunces-OFL.txt`.
- [Geist Mono](https://github.com/google/fonts/tree/main/ofl/geistmono): `GeistMono[wght].ttf`, stored as `GeistMono-Variable.ttf`; licence `geistmono-OFL.txt`.
- [Poppins](https://github.com/google/fonts/tree/main/ofl/poppins): Regular (400), Medium (500), SemiBold (600), Bold (700), ExtraBold (800) and Black (900); licence `poppins-OFL.txt`.

The booking form retains `--booking-body-font` and `--booking-heading-font`; the site layout retains `--font-poppins` and `--font-geist-mono`.
